# Unit-Converter

A web-based unit converter created for the CS 3350 mini-project.

## Features

- Time conversion
- Temperature conversion
- Data transfer rate conversion
- Data storage conversion
- Swap units functionality
- Scientific notation for very large or small results

## Technologies Used

- HTML
- CSS
- JavaScript

## Requirements

- A modern web browser
- Internet connection for the Lucide icon library
