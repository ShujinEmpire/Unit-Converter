# Unit-Converter

A web-based unit converter created for the CS 3350 mini-project.

## Features

- Time conversion
- Temperature conversion
- Data transfer rate conversion
- Data storage conversion
- Swap units functionality
- Scientific notation for very large or small results

## Technologies Used

- HTML
- CSS
- JavaScript

## Requirements

- A modern web browser
- Internet connection for the Lucide icon library
- Python 3 to run a local web browser

## How to Run

1. Clone the repository:

   ```bash
   git clone https://github.com/ShujinEmpire/Unit-Converter.git

2. Enter the Unit_Converter repository:
   
   ```bash
   cd Unit-Converter

3. Run the Python command to start a local server

   ```bash
   python3 -m http.server 8000

4. Then, in an internet browser, search:

   ```bash
   http://localhost:8000
